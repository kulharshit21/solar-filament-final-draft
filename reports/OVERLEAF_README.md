# Overleaf report package

Upload these three files to a new blank Overleaf project:

1. `OVERLEAF_MAIN.tex` and rename it to `main.tex`.
2. `figures/qualitative_predictions.png`.
3. `figures/submission_distribution.png`.

Compile with pdfLaTeX. The source is self-contained: it does not require `preamble.tex`, `main.bib`, or any external image other than the two included report figures.

The report intentionally separates the four technical pages from acknowledgment and references using page breaks, matching the organizer template's stated page limit.
